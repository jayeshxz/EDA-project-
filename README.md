🎬 Netflix EDA — Data Analysis & Visualization

Exploratory Data Analysis of Netflix Movies and TV Shows using Python.

📌 About the Project

This project explores the Netflix Movies and TV Shows dataset to discover trends, patterns, and interesting insights about the content available on Netflix.

Using Pandas, NumPy, and Matplotlib, the dataset is cleaned, analyzed, and visualized to understand Netflix's content library.
